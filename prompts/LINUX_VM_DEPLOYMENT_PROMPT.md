# Перенос редакции в Linux VM с существующей LLM

Работай с этим репозиторием и соблюдай AGENTS.md. До изменений сохраняй
в GitHub исходный снимок без секретов и runtime, а каждую законченную правку
сопровождай новой записью CHANGELOG.md по Europe/Moscow. Версии pyproject.toml
и max_postiz_agent/__init__.py должны совпадать.

Редакция размещена в Proxmox VM 112, Ubuntu 24.04, /opt/max-postiz,
4 vCPU, 10 GiB RAM, системный диск 120 GiB и контейнерный диск 160 GiB.
Панели: 10.20.30.45:4007 и 10.20.30.45:8090/hub. Адрес DHCP нуждается
в reservation на маршрутизаторе. Существующий WireGuard владельца имеет
source 10.77.0.2. Не открывай БД, OpenCode, VNC или debug ports в интернет.

Сохраняй LLM contract: OpenCode 127.0.0.1:4108 → общий API
http://10.20.30.95:8083/v1, Qwen proxmox/qwen35-9b и Ministral через
proxmox/qwen25-coder-7b. Не изменяй inference VM или другие гости без
необходимости. Секреты берутся только из игнорируемых локальных файлов.

Перед конфигурационными правками и переносом проверяй sending/unknown,
активные dispatches, mutation leases и паузу адресатов. Не перезаписывай
непустую БД восстановлением. Не запускай Windows и Linux publishers
одновременно. Сохраняй источники, историю версий и журнал отправок.

Postiz MAX — собственный max-browser provider. Согласование остаётся
в агенте для точного текста, revision, даты и адресата. Доставляет прежний
browser transport. Pending, owner_attested и доступ к каналу не являются
живой доставкой. Chrome работает с sandbox; вход владельца ручной через
защищённую owner-страницу. Не переносить Windows cookies в Linux.

Продолжая Reddit, учитывай реальное состояние: OAuth-заявка не отправлена,
официальная форма с VM вернула 403, API access/translation rights не получены.
Личный проект без монетизации. Не обходить ограничения, не подменять OAuth
паролем, не считать стандартный OAuth правом внешней перепубликации.
Контактные данные и готовая заявка — в игнорируемом локальном файле.

Целевой режим после разрешений: десять отдельных английских Reddit posts
каждые четыре часа, истории/наука/юмор без политики и NSFW; перевод Qwen,
review Ministral, LanguageTool, отсутствие повторов и проверяемая доставка.
До его включения реализовать durable scheduler, dedup, policy approvals
и обработку удаления источников и публикаций. При unknown не повторять
отправку автоматически. При нехватке материалов публиковать меньше.

Проверяй фактическую генерацию, public-origin frontend, owner auth,
живой bridge и сохранность состояний. Отдельно отмечай fixture tests,
реальные локальные вызовы и реальные внешние публикации. Финальные команды,
ограничения и откат описывай в docs/LINUX_DEPLOYMENT.md.
