# Промпт собственного адаптера MAX для Postiz

Работай в C:/script/20261011-Max postiz. Реализуй и проверь схему владельца:
локальная LLM → Postiz: редактор и календарь → наш агент: согласование
→ прежний авторизованный браузер MAX: публикация. MAX Bot API не используй:
владелец не создавал бота и выбрал браузерный транспорт.

Сохрани PostgreSQL, raw-архив, дедупликацию, источники, историю вариантов,
OpenCode 2.0.17 на 127.0.0.1:4108 и общий API http://10.20.30.95:8083/v1.
Основная модель proxmox/qwen35-9b; явный второй выбор proxmox/qwen25-coder-7b
соответствует Ministral 3 8B. Облачного fallback и publishing tools LLM нет.

Для Postiz 2.25.1 добавь max-browser provider в backend, orchestrator,
Temporal registry, frontend подключения, редактор и DTO. Подключи прежний
max_test/-79860712657053 штатным API без фиктивной Integration в БД.
Оставь адресат на паузе. Секреты держи только в ignored-файлах. Исходный
C:/script/20261005-Max не меняй; Пикабу — ручной маршрут, TG/VK выключены.

Postiz может передать пост на проверку и наблюдать pending/status.
Согласование в агенте замораживает ревизию, тело, дату, адресат, метаданные
и хеш медиа. Правка/удаление снимает согласование. Перед отправкой прочитай
авторитетный Postiz и байты медиа. Sending/unknown блокируют mutation;
истёкший lease не разрешает отправку. Для текста без источников требуется
отдельное owner attestation. Simulated/owner_attested не равны live delivery.
Browser worker обязан проверять hub Dispatch и TargetApproval до браузера
и перед кликом; не требуй legacy Intent для новой очереди и не включай старый
outbox. Повтори guard Postiz перед внешним эффектом. ID browser-... — локальная
операция; не выдавай его за native message ID или индивидуальную ссылку MAX.

Сохрани доказательства: тесты, PostgreSQL migration/locking/restore,
compiled provider contract, реальный pending HTTP-мост, браузерная проверка
редактора и импорт правки. Подготовь один черновик от настоящей Qwen.
Не отправляй пост без согласования конкретного текста и канала.
Неподтверждённые live gates и ограничения сборки опиши честно.
