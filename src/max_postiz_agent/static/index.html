Каналы

История отправок в MAX

Каждая карточка — отдельная попытка отправки. «Опубликовано» означает, что проект подтвердил появление поста в канале. «Отправка отклонена» означает, что эта попытка не завершилась публикацией.

Свежие записи находятся сверху. Если результат неизвестен, используйте «Сверить результат»: проект проверит существующую отправку. Будущие публикации находятся во вкладке «Календарь».

Управление каналом

Браузер MAX

Вход откроет отдельное окно браузера проекта. Проверка сверит выбранный канал и право публикации.

Автоматические изображения

Разрешённые бесплатные источники, локальная оценка и отдельное расписание каждого канала.

Дни и часы отправки меняются в разделе «Календарь».

Данные последней проверки изображений (JSON)

Служебный ответ: schedule — расписание, top — выбранные изображения, state — результат операции. Только для просмотра.


    

    
Собственный ролик

      
      
title — название, caption — подпись поста, rights_basis — основание прав, scenes — сцены. В сцене prompt описывает кадр, negative_prompt — что исключить, duration_seconds — длительность в секундах. Пояснения находятся рядом: внутри редактируемого JSON комментарии не допускаются.

Ключи и переменные окружения
Текущие значения не раскрываются. Введите только значения для замены; пустое поле оставляет прежнее значение.
