# Описание проекта
Цель: единый локальный редакционный процесс от RSS, HTML и JSON API до согласованного контент-плана и доставки. PostgreSQL хранит историю и состояния, OpenCode управляет прежней локальной LLM, Postiz подключается через документированный Public API.

Начальный охват по указанию владельца: прежние MAX и Пикабу. Telegram/VK предусмотрены через Postiz, но выключены. Прежний проект MAX и его конфигурация не заменяются; новый пакет и локальные процессы самостоятельны. Браузер MAX используется на месте под прежней эксклюзивной блокировкой, cookies не копируются.

Результат разработки: сборщики, PostgreSQL-миграции, архив и полнотекстовый поиск, редакционное ядро MAX, версии по адресатам, журнал согласования, рабочая очередь, ручной пакет Пикабу, панель, REST-интеграция Postiz, перенос и резервирование.

Условия живой приёмки: доступная локальная LLM; подтверждённый редактором текст; проверенные права на источники; активный адресат; для Postiz — запущенный экземпляр, ключ, интеграции и установленное ограничение обхода согласования. Тесты с имитацией транспорта не заменяют эти условия.
