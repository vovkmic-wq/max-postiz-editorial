# Проверка известных научных терминов

LanguageTool продолжает проверять весь перевод. Его исходный ответ сохраняется
целиком. Отсутствие слова в словаре само по себе не доказывает опечатку:
для трёх проверенных случаев предусмотрено отдельное доказательство написания.
Оно не является одобрением смысла или публикации.

| Английский оригинал | Проверенное написание | Первичный источник |
| --- | --- | --- |
| Hubble Space Telescope | Хаббл, Хаббла и ограниченный набор падежных форм в контексте телескопа | [ИКИ РАН](https://iki.cosmos.ru/news/2026/07/28/kak-provodit-nablyudeniya-v-vodorodnom-oblake) |
| Goddard Space Flight Center | Годдарда в названии центра космических полётов | [ИКИ РАН: участники проекта ЛЕНД](https://iki.cosmos.ru/research/missions/lend) |
| star-forming | конечный набор форм прилагательного «звездообразующий» | [Астрофизический бюллетень, САО РАН, том 78, № 3](https://www.sao.ru/Doc-k8/Science/Public/Bulletin/Vol78/N3/ASPB78_03_347W.pdf) |

Привязка требует английского термина вне URL, точного русского слова и его границ,
корректных UTF-16 offset/length LanguageTool и конкретного правила UnknownWord /
MORFOLOGIK_RULE_RU_RU / TYPOS. Для имён нужен также соответствующий русский
контекст. Повторное «Хаббл» допустимо при уже имеющемся полном наименовании
телескопа в том же тексте; доказательство сохраняет точный anchor и его позиции.
Похожие опечатки, латинские подмены, другие правила и слова остаются
неразрешёнными. Это не общий список разрешённых имён или префиксов слов.

Первичные страницы и PDF получены 27 октября 2026; полные снимки хранятся только
в игнорируемом runtime. Доказательство содержит URL и SHA-256 использованного
снимка; текущий HTML сайта может позднее отличаться от сохранённого.

- Hubble: `b52a2b774255f1304c5be2a2b13649d48d489405bd5e82efb0bf3f92b36cbce9`.
- Goddard: `0f2d233f60ddb756e49c4c361e4cf03e53f5cb79fa724c09153d25063f4c362d`.
- Star-forming: `551ffd315296b57fbbab779a48aa6feb5d35f985efac812e76f96a4442236421`.

Контракт `source-bound-terms-v1` предназначен для новых автоматических записей:
он закрепляется до моделей и входит в историю подготовки и проверки. Старые
записи без контракта сохраняют прежние правила; отказы, raw и отмены не
переоцениваются и не восстанавливаются. Исторические human/recovery маршруты
не включают новый словарь автоматически.

Проверка Ministral по полному оригиналу, остальные замечания LanguageTool,
hard gates, права, точная версия согласования и запрет дублей сохраняются.
Например, подмена *Dove* словом «Голубые» и замечание LT для «флоккулентом»
этим словарём не снимаются. Эти справочники не становятся источниками статей
для внешней публикации.
