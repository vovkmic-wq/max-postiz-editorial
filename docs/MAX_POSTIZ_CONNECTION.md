# Подключение тестового MAX к Postiz

Проверено 13 октября 2026, версия 0.4.0. Канал `-79860712657053`,
профиль `max_test`, подключён внутри Postiz 2.25.1 как **MAX — браузер**.
Подключение создано штатным API Postiz, а не прямой записью Integration в БД.

По выбранной владельцем схеме используется прежний авторизованный браузер MAX.
Digital ID и браузерная сессия не создают токен Bot API; этому адаптеру токен
бота не требуется. Vezdepost Bot API provider не используется.

Postiz отвечает за редактор и календарь, наш агент — за отдельное согласование
и доставку через браузер. Сохранение или постановка в календарь Postiz не
согласуют текст. Все адресаты пока на паузе, новых внешних сообщений нет.

Создан черновик от Qwen3.5-9B; правка в реальном Postiz импортирована как
ревизия 2. Реальный pending/status установленного provider к агенту проверен.
В 0.4.1 выполнена живая отправка после явного согласования;
[результаты тестовой публикации](MAX_TEST_PUBLICATION_REPORT.md).
