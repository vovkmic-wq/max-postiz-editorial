# Тестовая публикация MAX — 13 октября 2026

**Область документа, сверено для 0.11.5 29 октября 2026:** Историческая первая публикация 13 октября; это не текущий размер резерва или новая приёмка.
Актуальные эксплуатация и состояние: [VM](VM_EDITORIAL.md), [выпуск 0.11.5](RELEASE_0.11.5.md).

Версия агента 0.4.1. Overlay Postiz 0.4.0 на базе 2.25.1.
Владелец явно согласовал точный текст без вложений для прежнего max_test.
Публикация прошла в 15:21 Europe/Moscow через полную выбранную цепочку:
Postiz: календарь → наш агент: согласование → браузер MAX → результат Postiz.

| Проверка | Фактический результат |
|---|---|
| Postiz | Существующий draft переведён в QUEUE с точной датой |
| Агент | Owner attestation и approval ревизии 3; неизменный snapshot |
| Отправка | Одна попытка, один новый текстовый пост |
| Браузер | Текст найден после reload, затем после новой сессии; ровно одно совпадение |
| Postiz после результата | PUBLISHED |
| Temporal workflow | COMPLETED |
| Завершение теста | Все адресаты paused, повторная отправка не запускалась |
| Регрессия исправления | 48 browser/bridge + 16 hub/PostgreSQL = 64 passed; Ruff passed |

До внешнего запроса обнаружен оставшийся legacy gate browser worker:
он проверял Intent, которого новая очередь Dispatch не создаёт. В 0.4.1
worker проверяет действующую sending lease, дату, TargetApproval, паузу,
версию, полный snapshot, адресата и вложение; повторяет свежую проверку
Postiz непосредственно перед кликом. Legacy очередь не включалась.

Внешний эффект подтверждён сохранением сообщения в настоящем MAX после
reload и новой сессии. Подтверждение через независимый MAX Bot API не
заявляется. External ID browser-... обозначает локальную операцию;
native message ID и индивидуальная ссылка MAX не извлечены.

Приватные доказательства хранятся только в ignored data:
max-test-publication-verification.json, max-test-publication-browser-proof.json,
max-test-publication-temporal-proof.json, max-test-publication-confirmed.png
и журнал browser-publications. Они не входят в исходный архив.

Этот тест проверяет одну согласованную текстовую публикацию.
Вложения/видео, правка/удаление поста и чистая повторная сборка текущего
source Dockerfile остаются отдельными gates. Пикабу, Telegram и VK
в этой проверке не публиковали.
