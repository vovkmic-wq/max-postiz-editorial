# Выпуск 0.11.5 — 29 октября 2026, Europe/Moscow

Python 0.11.5 установлен на редакционной VM. Это версия исходников, тестов,
промптов и документации; приватная конфигурация, БД, браузер и медиа
переносятся отдельно. Подробная эксплуатация: [VM_EDITORIAL](VM_EDITORIAL.md).

## Что изменено

- План MADLAD для заголовка и полного текста строится до первого HTTP.
  Когда слишком ранняя граница предложения не подходит, используется
  допустимый пробел внутри прежнего лимита 600 символов. Целые слова,
  URL, числа, абзацы и хвост исходника сохраняются; overlap не включён.
- Новый native `TRANSLATION_PREFLIGHT_UNSPLITTABLE_INPUT` доказывает локальный
  отказ до сети. Отдельное точное завершение источника требует исходника,
  конфигурации, provenance, trace, изображения, durable claim и аудита.
  Прежние generic ошибки, завершённый перевод заголовка, timeout и unknown
  автоматически безопасными не становятся. Источник остаётся использованным.
- В состав входят исправления 0.11.3–0.11.4: версионированная практическая
  рубрика `hourly-practical-v2`, ограниченный вход Qwen без удаления исходных
  замечаний и сравнение эквивалентных Cloudflare-контактов при неизменных
  правах, raw proofs и изображении. Старые политики и отказы сохраняются.
- Для новых публикаций действует `article-illustrated-v2`: проверенное фото
  статьи, настоящий жирный заголовок, обычное тело, источник, лицензия,
  полный credit и «Перевод и адаптация.». Архивная и машинная строки исключены.

raw и настройки. Source/import/metadata/health подтвердили одну версию.
Новая миграция не нужна: схема 0008. Образ Postiz остаётся
`max-postiz-linux:0.11.2-illustrated-cas`; Python и образ имеют разные версии.

состоялась **29 октября в 22:24:06 МСК на 0.11.4**, до установки 0.11.5:

назначенных отправок нет, одна новая статья готовится. Накоплено 21

постоянного состояния: проверяйте панель Postiz перед эксплуатацией.

Права, полный оригинал, проверки фактов/чисел/ссылок, независимые Ministral
и LanguageTool, максимум два editor claim, дедупликация всей истории,
интервал доставок от 3600 секунд и остановка при unknown сохраняются.

desktop heartbeat и не изменяет работающую очередь.

## Обновление и исходники

Перед обслуживанием сверяют QUEUE, sending/unknown, активные claims и leases,
сохраняют закрытый backup обеих БД и runtime. API оставляют доступным для
уже назначенных Postiz-задач; одного переключения общей паузы недостаточно.
Не применяйте исторические Windows/Hub-инструкции к действующей VM.

Git содержит README, инструкции, правила AGENTS, append-only CHANGELOG,
схемы, миграции, промпты, безопасные примеры и тесты. Действующие `.env`,
ключи, cookies, raw, фотографии, модели и Docker volumes в Git не входят.
История изменений: [CHANGELOG](../CHANGELOG.md); все документы:
[навигатор](README.md).
